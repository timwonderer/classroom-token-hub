Security requirement: {{ recovery_min_students }} students per class

Every class you teach must have at least {{ recovery_min_students }} students who have claimed their accounts. Recovery randomly picks 2 of them to confirm your identity, and with fewer students that pick would be predictable, so recovery cannot start. This protects your account from someone who knows a small class well.

How Recovery Works
  • Enter a join code and student username pair for each class you teach, one row per student
  • Rows per class: 6 if you teach one class, 3 each for two classes, 2 each for three classes, and 1 each for four or more. If a class has fewer students with claimed accounts than that, enter all of them
  • Each student username can be used only once, even if that student is in more than one of your classes
  • All pairs must be correct to proceed
  • Selected students will receive a verification prompt in the app
