{% endcall %} {% call help.topic('stu-claim', 'person_check', 'How students claim their account') %}

Students claim their account by clicking I need a student account on the student login page.

What students need:

  • Join Code — Found in the Class Roster tab for the current class
  • First Name — As entered in your roster
  • Last Name — As entered in your roster
  • Claim Code — Only when another unclaimed student shares their name. The system generates it; find it in the Unclaimed Seats list
  • Class — The student must use the join code for this class

Account Setup Steps:

  1. Student enters their information and gets a theme word prompt
  2. A unique username is auto-generated using their theme word
  3. Student sets a 4-6 digit PIN (for quick access)
  4. Student creates a long passphrase (for security)
{% call cards.alert_card('danger', 'The username is shown only once', icon='warning', body_class='mb-3') %}

The username is shown only once during setup. Students must record it. If forgotten, you'll need to reset their account.

{% endcall %} {% call cards.alert_card('info', 'Set up accounts in class', icon='lightbulb', body_class='mb-0') %}

Have students complete account setup in class so you can help if they have issues. Although not recommended for security reasons, consider keeping a secure record of usernames for your class so you can assist with forgotten usernames.

{% endcall %} {% endcall %} {% call help.topic('stu-edit', 'person_text', 'How to update student info') %}

What you can update: First name, last name, teacher notes, and account reset.

How to update:

  1. Go to the Class Roster tab
  2. Click Edit next to the student's name
  3. Update their information
  4. Click Save. The changes take effect immediately
{% call cards.alert_card('info', 'Name changes are display-only', icon='info', body_class='mb-0') %}

Changing a name only changes how it is displayed. It does not change the student's login or the name used to claim a seat.

{% endcall %} {% endcall %} {% call help.topic('stu-reset', 'restart_alt', 'How to reset student login') %}

Use reset when a student forgets credentials or cannot log in. Resetting preserves account data and issues a recovery code.

{% call cards.alert_card('warning', 'The recovery code expires in ten minutes', icon='schedule', body_class='mb-3') %}

Give it to the student right away. A new code replaces any earlier one.

{% endcall %}

The student enters the code from account recovery on the student login page, then chooses a new username, PIN, and passphrase.

More than one student has the same name

The seat stays in this class. Its balance, transactions, attendance, items, and teacher notes stay with it for the next claimant. The current account loses access to this seat. If it has no other classes, that sign-in account is deleted.

Enter the name this seat should carry from now on. It becomes the name shown on your roster and the name the student types to claim the seat, so the two always match. Teacher notes and the seat's records are unaffected. To consolidate accounts, the student should sign in to the account they want to keep and join this class.

If another unclaimed student has the same names, the system gives each of them a claim code. Find it in the Unclaimed Seats list and give it to the student.
