## CodeQL #327 — exception disclosure

- Query: `py/stack-trace-exposure`, medium; authenticated teacher request.
- Source/sink: `execute_hall_pass_adjustment()` raises `ValueError`; the bulk
  route interpolated the exception into `errors`, then returned it as JSON.
  Teacher/class authorization does not sanitize exception contents.
- Disposition: real exposure boundary repaired in this change. A shared route
  formatter returns only three literal, reviewed validation messages, otherwise a
  generic failure. It never returns exception-derived text. The detail route uses
  the same formatter because it called the same FEAT and flashed raw exceptions.
- Bulk errors use the seat's public ID, not a student's name or internal ID.
  The outer bulk failure log records the exception class, not its contents.
- Existing useful quantity/replay/removal guidance and partial-result behavior
  are retained. Regression tests inject private-looking exception text into both
  route surfaces and assert it is absent from responses/flashes and captured logs.
- GitHub alert is not dismissed: merge and CodeQL analysis must establish closure.

## Dependabot #100 — CVE-2026-114603

- Direct runtime dependency `opentelemetry-api==1.44.0` is in the affected range.
  [Upstream advisory](https://github.com/open-telemetry/opentelemetry-python/security/advisories/GHSA-xcq7-p3pf-p88h)
  identifies quadratic processing of crafted tracestate headers and fixes from
  1.45.1. Proxy limits may reduce exposure; they are not the remediation.
- Disposition: update API, SDK and HTTP exporter together to 1.45.2; semantic
  conventions and Flask/Requests/SQLAlchemy instrumentation to 0.66b2. Installing
  the complete requirements file resolves successfully; `pip check` passes.
- Existing separate dependency proposals #1607, #1608, #1610, #1611 and #1612
  overlap these coordinated pins. They were inspected, not merged or closed.
- The installed parser uses plain comma splitting and whitespace stripping.
  Contrary to one advisory paragraph, it does not reject every padded header over
  8,192 characters. The regression therefore checks the actual CPU-stall defect:
  a long malformed header must complete in a subprocess with a five-second limit;
  valid tracestate values must still parse. No exploit requests reach a server.
- Negative proof: the same test against isolated API 1.44.0 times out (one failed,
  one passed); against 1.45.2 both pass. No timing microbenchmark threshold is used.
- Dependabot closure requires the fixed manifest on the default branch. Production
  remains unchanged until the approved application release process deploys it.
