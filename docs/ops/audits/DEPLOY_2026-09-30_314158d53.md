## Not part of this release

- **2026-09-30 20:39-20:47 UTC outage (before this release).** Four gunicorn worker timeouts took the single
  worker down for about eight minutes. Cause: a signed-in student's claim request for a seat in their own current
  class held `classes`/`seats` row locks outside any FEAT, and the request-trace writer's second connection then
  waited on that lock (an application self-deadlock Postgres cannot detect). Reproduced; fix and mitigations are
  pending owner decision. Unchanged by this release.
- **Operations changes approved on 2026-09-30** (Grafana anonymous access off, Tempo disabled,
  `OTEL_TRACES_ENABLED=false`, Loki storage moved with 14-day retention, duplicate journal lines dropped) had not
  been applied at release time. `OTEL_TRACES_ENABLED` therefore remains `true` until the next application restart
  after that change.
