### Why this release

On 2026-10-02 at 13:40 UTC a teacher who had signed up four minutes earlier pressed **Run Payroll Now** before
saving payroll settings. Settlement correctly refused, because no payroll setting governs the rate (FEAT-PROD-004
fails closed), but the route's catch-all answered HTTP 500 *Unexpected error during payroll.* The refusal comes
before any write and the route rolled back: nothing was paid or recorded. The teacher saved payroll settings
42 seconds later and set up the rest of the class without further errors; the failed attempt is the only payroll
run on that class since. #1470 answers the refusal with 409 and guidance, and disables the button until the class
has payroll settings.
