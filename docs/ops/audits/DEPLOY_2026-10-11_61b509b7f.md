### Why this release

- **Stored XSS via hall-pass destination and announcements, GHSA-7fxj-gpw3-23g3 (S1 Critical, S4 Medium; #1535).**
  A hall pass's `destination` is student-supplied free text, serialized to the teacher-facing JSON API under the
  key `reason`, and was interpolated unescaped into `tbody.innerHTML` in `templates/admin_hall_pass.html` — a
  script-bearing destination ran in the teacher's session once approved and viewed. The same value was also
  exposed via `student_dashboard.html`'s `attendance_state_json|safe`, running in the student's own session
  immediately. Separately, `nl2br_filter` (`app/__init__.py`) marked a teacher's raw announcement text safe with
  no escaping, so a compromised teacher account could run script in every student's dashboard in that class. All
  three sinks now escape before introducing trusted markup.
  **Production forensics (read-only, run ahead of this release):** `hall_pass_logs.destination`,
  `pending_actions.payload->>'destination'` (`FEAT-PROD-002`), and `announcements.message` all returned zero rows
  containing a raw `<` — no evidence either sink was ever exploited in production.
- **An item-removed reversal entry is not reversible (#1532; owner report 2026-10-10).** Already on `main` as the
  untagged `c2f16fb11` hotfix; this release just tags it in with #1535. See the `[2.2.2]` CHANGELOG section for
  detail.
