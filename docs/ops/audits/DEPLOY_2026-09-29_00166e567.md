# Deployment record: 2026-09-29 production release, `00166e567`

**Type:** Hotfix release under `SOP-DEP-002`. No migrations. Fixes a production regression
introduced by the previous release (`29b99b140`, #1442): student setup was answering HTTP 400
("The referrer header is missing.") because the setup pages' `Referrer-Policy: no-referrer` header
conflicted with Flask-WTF's strict HTTPS CSRF validation, which requires a same-origin `Referer`
even with a valid token.
