## Contents and migrations

The release moves the supported migration lineage's root to the v2.0.0 launch baseline. It fixes non-compounding simple interest, two production deadlocks and a bill-cycle race. It keeps request URLs, caller request ids, statement parameters and typed student names out of logs. It shows projected pay to students. It adds CI enforcement of fresh-install bundle derivation and a declared supported fresh-install release. Full contents are in CHANGELOG `[2.6.0]`.

**Migrations.** The lineage changes from 191 files with head `a0faf8b2a35d` to 22 files with root `d7a3e9b1c5f2` and head `4fad9d362d0d`. Production executed one revision:

```text
Running upgrade a0faf8b2a35d -> 4fad9d362d0d, Drop eligible_for_reward from issues (DOM-SUP-001 v1.11)
```

- **Baseline replacement ([#1851](https://github.com/timwonderer/classroom-token-hub/pull/1851)).** Production never runs it; it was already past `d7a3e9b1c5f2`. Its 171 pre-launch revisions are now provenance in `migrations/archive/v2_prelaunch/`.
- **Retired revisions (announcement).** A database recorded at any of the 170 pre-launch revisions other than `d7a3e9b1c5f2` is refused by `flask db upgrade`. No known supported installation is affected. Evidence: `docs/ops/audits/BASELINE_REPLACEMENT_2026-11-24.md`.
- **Fresh installs.** The supported fresh-install release stays **v2.5.0**, bundle `a0faf8b2a35d` (SOP-DEP-002 §VII.B). v2.6.0 ships no bundle. New installations start at v2.5.0 and upgrade.
- **No dependency or setting changes.** `requirements.txt` is unchanged since v2.5.0, and there are no new required settings.
