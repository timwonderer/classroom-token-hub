## 2a. One change was reverted — read this first

**Finding 38 was not a defect and its fix was reverted.** The observation was
real: the daily-limit close writes `reason_code = done_for_day`, the same code
used when a student chooses to stop, when the day ends, and when a hanging hall
pass closes — four events, one code — and the job's explanatory string is
computed and then discarded because no column exists for it.

But `DOM-PROD-001` **mandates** that, in five clauses: §302 closes the
enumeration to three values, and §316, §317, §318 and §319 each specify
`done_for_day` by name. Adding `daily_limit_reached` and `end_of_day` broke three
`test_DOM_PROD_001__*` tests, which is exactly what tests named for a rule are
for. Reverted in full; the three tests pass again.

This is a spec question, not a bug. It is written up as finding 38 in the audit
record with the exact question for you to answer. **Do not re-attempt the code
change without amending DOM-PROD-001 first** — the direction of authority runs
doc → code, and this went the other way.

**36 — the hostile-timezone experiment (agreed: run separately).**
Mitigated for the specific case: `Pacific/Kiritimati` (UTC+14) is a provisioned
test classroom timezone and the rent date assertions run against it. The larger
experiment is to run the **whole suite** under an ambient `Etc/GMT+12` (UTC−12),
preserve the full result, and classify each failure rather than assume the
application is wrong. `INV-ARC-015` gives the rule: SLE derives from UTC, CLE
from the Canonical Class Timezone, and neither should derive from wherever the
process thinks it lives. Do **not** make it the sole CI environment before
seeing the fallout; production-parity UTC testing stays useful.

## 7. Method

`SOP-DEP-001` §XI.A records the adversarial technique this campaign used:
predict before producing; controlled comparison over a single negative; reach the
state as a user would; arrange fixtures so outcomes cannot be confused; confirm
at the data layer; record evidence, not verdict.

The recurring defect shape across all 38 findings: **a rule that exists
normatively with no control enforcing it**, and **surfaces asserting things that
are true in a narrow sense and misleading in the sense that matters**.
