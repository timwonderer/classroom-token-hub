# Troubleshooting the Student Dashboard

Use this guide when the Student Dashboard does not show the attendance status, balances, alerts, or recent activity you expect.

## Attendance does not update

- Check the **Attendance** card. **Inactive** means the work clock is not running.
- Choose **Start Work** to begin tracking time. **Break** stays unavailable until you are working.
- If the status or timer does not change after reloading, report the exact status and time shown to your teacher.

## A balance or transaction looks wrong

- Confirm that the correct class is selected in **Switch Class**. Balances and history belong to the selected class.
- The dashboard shows a short **Recent Activity** list. Open **Accounts** for the fuller transaction history.
- If one transaction is incorrect, use **Report an issue with this transaction** on that row so the transaction is attached to the report.

## An alert or help link is missing

- Alerts are conditional; they do not appear when there is nothing to report.
- Choose **Need Help?** to open the contextual guide. Use **Open full guide** for instructions or **Troubleshooting** for problem-solving steps.
- If the help panel opens without its links, reload the page and report the page title and browser being used.

## When to contact support

Report the page title, selected class, visible status, and the exact error message when the problem remains after a reload. Do not share your passphrase in the report.
