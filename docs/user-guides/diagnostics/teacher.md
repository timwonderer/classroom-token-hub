## Direct Support Tickets

Teachers can submit support tickets directly from **Help & Support** (`/admin/help-support`). The ticket is always filed under your active class — there is no separate scope picker, so switch classes first if the problem belongs to a different one — and it is delivered directly to system administration without a teacher triage step. You must have at least one class set up before you can submit a ticket; if you have no classes yet, create a class first (see [Students and Join Codes](teacher/students.md)).
