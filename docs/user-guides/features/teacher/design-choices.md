# Is Classroom Token Hub Right for You?

## Overview

Classroom Token Hub makes some choices that other classroom economy tools don't. Most of them come from one idea: the economy should teach through consequences that students can see and check, and the rules bind the teacher as well as the students.

Some of these choices will be exactly what you want. Others may get in the way of how you run your class. We'd rather you knew that up front. Each guide below explains what the app does, why, and which other products handle that feature differently, with links so you can compare for yourself.

## The choices

| If you want… | Classroom Token Hub instead… | Read |
| --- | --- | --- |
| Students to sign in with Google, Clever or Microsoft | Uses its own usernames and passphrases, and keeps no student email | [Class Setup](classroom/class-setup.md#why-it-works-this-way) |
| A co-teacher, or one economy across the school | Gives every class one teacher and keeps every class sealed | [Class Setup](classroom/class-setup.md#why-it-works-this-way) |
| To delete a transaction or set a balance | Lets you void an entry, which stays visible | [Transactions](economy/transactions.md#why-it-works-this-way) |
| Classroom jobs or pay for behaviour | Pays a wage for time worked, at one rate for the class | [Payroll Settings](economy/payroll-settings.md#why-it-works-this-way) |
| Avatars, XP, badges or a leaderboard | Keeps balances private, with no rankings or scores | [Students Overview](classroom/students-overview.md#why-it-works-this-way) |
| To cancel or refund a student's insurance | Honours the policy until the student cancels at the period boundary | [Insurance Enrollment](bills/insurance-enrollment.md#why-it-works-this-way) |

## Other products at a glance

- [ClassBank](https://www.classbank.com/) is a full digital classroom economy with jobs, bills, a store and savings. It is free for individual teachers, with paid Pro and Schoolwide plans.
- [My Classroom Economy](https://myclassroomeconomy.org/en/digital) is a free program from Vanguard for grades 3–8, in [digital and printable](https://myclassroomeconomy.org/en/overview) versions.
- [Banqer](https://www.banqer.co/nz/primary/how-it-works) is a classroom economy with taxes, insurance and interest, built for New Zealand schools.
- [Schoolhouse Moolah](https://apps.apple.com/app/id6749143193) is a free iPad app for grades K–5.
- [ClassDojo](https://www.classdojo.com/points), [LiveSchool](https://www.whyliveschool.com/pricing) and [PBIS Rewards](https://www.pbisrewards.com/) are behaviour-points tools rather than banking simulations.

The original Classcraft platform closed on 30 June 2024, so it is not listed.
