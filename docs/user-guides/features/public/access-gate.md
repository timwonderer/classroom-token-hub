# Temporary Access Restrictions

Classroom Token Hub uses Cloudflare Access to restrict entry during prelaunch or
operational work. You may see a Cloudflare Access email-code screen before reaching
the app. This screen is separate from your Classroom Token Hub sign-in.

If you have explicitly been granted access, use your approved email address.
Completing this step does not sign you into a teacher or student account; the
usual application sign-in is still required. An email code does not grant access
to an address that is not authorized by the Access policy.

Teachers and students without approved access should wait until public access
reopens. You do not need to create a new app account or reset your password.
Check the [status page](https://status.classroomtokenhub.com) for published updates.
An access restriction alone does not tell you whether the app is healthy or down.

The app has no maintenance bypass link. Refresh the app after access reopens.
