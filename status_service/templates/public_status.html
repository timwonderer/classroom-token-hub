Request evidence
{{ icon('chevron_right', 'sm', 'chev') }}What the numbers mean

We check the app and its database every minute. A check expires after five minutes if polling stops, and it doesn't test every classroom action.

The areas above describe the requests we saw in the last five minutes. A quiet area shows when it was last seen, kept for up to seven days as history rather than a claim about now. One server error is enough to show. Refusals and missing pages don't count as an outage.

We flag HTTP 5xx above 2%, HTTP 404 above 5%, and p95 above 1,500 ms. p80 and p95 are the response times that 80% and 95% of requests came in under. Application requests include our own health checks.

History counts the five-minute windows that stayed within those thresholds, sampled once a minute. It isn't uptime or request success. Empty windows and missing or stale monitoring are left out, and older windows required 20 requests. Dates use UTC.
